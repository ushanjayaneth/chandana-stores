# Asset credits

Grocery illustrations in `public/images/grocery/` and the store mark in `public/icons/retail.svg` are original SVG drawings included with this template. PNG app icons are deterministic browser renders of that store mark. No remote product-image service is required.

The interface uses Lucide icons and Inter from their installed packages. Retain those packages' license notices when redistributing. Uploaded customer/product photos remain the responsibility of the shop using them.

Product photo search uses [Open Food Facts](https://openfoodfacts.github.io/openfoodfacts-server/api/tutorials/license-be-on-the-legal-side/) and [Open Products Facts](https://world.openproductsfacts.org/terms-of-use). Their product photos are credited to the catalogue contributors under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). The POS stores the source product reference with imported photos and resizes and compresses them for offline use. Catalogue results use product names and package data to help identify the photo.
